Que es un lenguaje de marcas?
Un lenguaje de marcas es un lenguaje de programación que se utiliza para estructurar y presentar contenido en la web. Los lenguajes de marcas utilizan etiquetas para definir elementos y su formato, como HTML (Hypertext Markup Language) y XML (Extensible Markup Language).
Que es CSS?
CSS (Cascading Style Sheets) es un lenguaje de estilo utilizado para describir la presentación de documentos HTML o XML.
Que es HTML?
HTML (Hypertext Markup Language) es un lenguaje de marcado utilizado para crear páginas web.
